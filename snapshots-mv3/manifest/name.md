The `"name"` key (required) is a short, plain text string (maximum of 75
characters) that identifies the extension. For example:

    {
      "name": "My extension name"
    }

You can specify a locale-specific string; see [Internationalization](https://developer.chrome.com/docs/extensions/reference/api/i18n)
for details.

It is displayed in the following locations:

- Install dialog
- Extensions page (chrome://extensions)
- [Chrome Web Store](https://chrome.google.com/webstore)

See also [Short Name](https://developer.chrome.com/docs/extensions/reference/manifest/short-name).
